# Computer Graphics sandbox

Learning through projects

## Project 1 Rendering (C++)
- Built a ray tracer to render 3D scenes with diffuse and mirror surfaces, direct and indirect lighting, shadows, and antialiasing
- Implemented ray-mesh intersections using the Möller–Trumbore algorithm and Bounding Volume Hierarchies to accelerate rendering

## Project 2 Geometry Processing & Fluid Simulation (C++) 
- Built a 2D free-surface fluid simulator using Voronoi and Power diagrams, Sutherland–Hodgman polygon clipping, and semi-discrete optimal transport with L-BFGS optimisation
- final simulation combines particle movement, gravity, and cell-based forces to animate fluid motion

## Project 3 Mesh Parameterisation (C++)
- Explored flattening a 3D triangular mesh into a 2D representation using Tutte embedding
- Identifying boundary vertices, mapping them onto a circle, and iteratively updating interior vertices using their neighbors

## Project 4 Diffusion Models (Python, PyTorch)
- Explored image generation using a U-Net-based diffusion model, starting from random noise and progressively denoising it to reconstruct an image
- Worked with pretrained model and implemented reverse diffusion sampling process
